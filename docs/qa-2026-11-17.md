## Findings and corrections

- The remote backup retention filter used `-mtime +14`, which rounds age down to
  whole days. A file aged 14 days and one hour was retained. The filter now uses
  `-mmin +20160` for a 14-day policy. The regression checks the actual generated
  retention command. The original and corrected GNU find predicates were also
  exercised against a synthetic aged file. See
  `graphify-out/qa-2026-11-17-retention.txt`.
- Graphify's aggregate injector retained an obsolete per-ticket metadata index
  after combining execution records. It now indexes every included ticket
  context file. Source/evidence relationships remain attached to each ticket.
- Integration conflicts were resolved by preserving the latest hardware and
  operator protocols together with the documentation evidence ledger.
- The integrated browser gate exposed horizontal Menu-page overflow at 320 px
  after PostgreSQL fixtures added long category labels. Runtime DOM inspection
  identified category badges with an unbounded flex width. Category controls and
  badges now fit the container and long labels wrap. The actual local API/web
  browser suite passed all 53 checks with the populated database. A confirmation
  measured document width 320 at viewport width 320 and reviewed mobile/desktop
  screenshots. The existing required database-plus-browser CI sequence retains
  this regression coverage.
